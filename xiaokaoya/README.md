## 运行

使用 Node.js 24 与 pnpm。`pnpm install` 后执行 `pnpm setup:runtime` 下载官方 Electron 运行时，再执行 `pnpm dev`。`pnpm build` 构建桌面程序，`pnpm test` 验证业务与数据库，`pnpm test:e2e` 验证真实 Electron。`pnpm dist` 生成完整离线 NSIS 安装程序。妹妹使用安装包时不需要这些开发工具。
