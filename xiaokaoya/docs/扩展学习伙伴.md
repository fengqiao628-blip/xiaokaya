# 扩展学习伙伴

伙伴与学习业务相互独立。运行时只读取 `src/companions/catalog.json`，不按动物 ID 编写业务分支。

添加狐狸或熊猫时：

1. 在 `public/companions/<新动物ID>/` 放入原创/有授权的 SVG 插画。
2. 在 catalog.json 增加唯一 ID、名称、简短描述、颜色和三种状态素材路径：study、rest、celebrate。
3. 构建并验证选项、重开后偏好保存和三种状态。无需修改首页、数据库或任务业务代码。

新增状态类型属于独立扩展，需要同步定义状态及默认替代图。素材缺失时展示默认伙伴；伙伴名称和偏好不写入任务或学习记录。

当前 5 种伙伴、每种 3 个状态，共 15 个独立 SVG。`scripts/generate-assets.mjs` 是素材创作工具，不参与应用运行；以后增加手工素材不需要更改它。
