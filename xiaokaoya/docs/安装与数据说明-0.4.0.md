# 小考鸭0.4.0 · 安装、升级与第四阶段使用说明

本版交付第四阶段：年/月/周/日日历、每周目标、任务日期安排、待安排池与手动考试日期。保留前三阶段功能。Windows x64安装后可独立离线使用，无需账号、服务器、Node.js或浏览器地址。

## 安装与覆盖升级

1. 升级前在旧版导出一份完整JSON，保存输入并完全关闭“小考鸭”。
2. 解压ZIP，运行Xiaokaoya-Setup-0.4.0-x64.exe。单独的exe也可直接安装；不要从ZIP预览窗口运行。
3. 从Windows桌面或开始菜单的“小考鸭”图标打开，核对“关于与数据”的版本、原有年度档案、任务和伙伴。正式验收统一使用此入口。
4. 首次打开V1/V2/V3旧库，程序先保存完整升级前快照并回读验证，写入恢复日志后才迁移到V4。原业务行保留，新增四张表；不会编造旧任务过去的日期调整记录。
5. 核对无误后导出一份新的V4完整JSON。升级失败显示错误并保留旧库或保护快照，不自动清空数据。请保留错误信息和快照，不要删除profile或用旧程序强行打开已经升级的库。

程序未签名，Windows可能显示未知发布者。请核对来源及附带的SHA256SUMS-0.4.0.txt。安装目录仅保存程序；覆盖升级与普通卸载均保留用户数据。

## 日历与自由安排

点击左侧“学习日历”，可切换年、月、周、日和待安排池。日期定位支持1900—9999年，2027—2029以后无需增加年份配置。周一是每周起始日，跨年周和闰日按实际日期生成。

“设置本周目标”保存本周总小时数、重点说明和所选年度科目的目标小时数。科目自由选择；总目标与各科分配独立，界面显示分配量，允许留出机动时间。每天不强制相同时间，普通学习日2—4小时只是使用建议。切换日期可以设置不同周的目标。

周概览区分本周总目标、预计已安排、实际学习和任务完成。概览包含全部科目，不随下方筛选变化。预计时长来自任务；实际学习只来自已确认的学习记录，勾选完成或调整日期都不会增加实际时长。记录录入和倒计时在第五阶段开发，所以现有测试数据仍可能显示实际0分钟。

下方可按考试分类、年度科目、任务状态和普通学习/复习筛选。日历内的任务数对应筛选结果；点击某天查看当天安排。不同年度的同一科目分别管理。

## 待安排池、延期与记录

- 创建任务时可以选普通学习或复习，并关联同年度章节；勾选“暂不安排日期，放入待安排池”后，任务不计入任何一天的预计时间。
- 待安排池默认包括未定日期任务和过期未完成任务。过期任务保留原日期，仍能在原日历查看，不会每天自动复制或滚动到今天。
- “安排日期”“调整日期”“移入待安排”“延期”均修改同一条任务，保留任务ID与原有关联。日期变化与说明会写入“安排记录”；旧任务从第一次实际调整开始留档。
- “延期”只用于有原日期、尚未完成的任务，新日期必须晚于原日期。一般调整日期可以向前或向后移动，并保留原状态。
- 勾选任务完成只改变完成状态；已完成任务可以取消勾选。完成和延期不代表已报名、已通过，也不改变教材进度或星级。
- 已归档周期不能新增安排。待安排池默认隐藏归档周期的任务，勾选“显示归档周期中的待安排任务”可查看；历史日历和原有关联保留。

## 手动考试日期

点击“管理考试日期”，按年度科目维护报名开始、报名截止、缴费截止、准考证打印、考试、成绩公布六类日期。日期由用户填写，程序不会猜测官方时间，也不会自动改变学习状态、报名状态或考试结果。

考试日期与“我的科目”年度档案使用同一条记录，两处修改后保持一致。其余五类节点可修改、停用和恢复；停用记录仍随完整JSON保留。日期提醒只显示在日历，不自动生成学习任务。

## 完整备份、恢复及CSV

“数据与备份”导出完整JSON，包含已实现的全部业务数据、偏好和历史。V4新增周计划、每科周目标、任务日期变更历史、考试日期节点均纳入完整备份与数量预检。

恢复流程：选择JSON预检 → 核对数量、版本和警告 → 确认整体替换 → 保存并验证恢复前快照 → 单事务替换全部表 → 复核。失败会原子回滚或使用保护快照还原，异常中断后启动先检查日志。相同内容重复恢复不会追加数据。

V1—V3备份按原版本校验，再在内存转换为V4，原文件不改动。旧备份没有后来新增的内容，整体恢复会用备份内容替换当前数据，新增周计划等可能变为空；务必核对预检差异。恢复前快照可用于找回，没有自动合并功能。

CSV现可分别导出学习任务、学习记录、科目周期、学习资料、章节与进度、每周计划、各科周目标、任务安排历史和考试日期。任务CSV区分普通学习/复习，未定日期留空；停用节点和未选入本周的目标行标记保留。CSV供Excel/WPS查看，不能用于完整恢复。

每日首次使用自动保存日常快照，保留最近14份已验证文件；升级前、恢复前、手动快照不自动删除。保护快照失败会阻止危险操作，日常快照失败会提示。单个文件上限256MB，超出会停止，不截断。摘要用于检测损坏，不证明来源。

请定期把完整JSON另存到其他磁盘或设备。本机快照与数据库在同一台电脑，不能防止整块硬盘损坏。导出回执记录成功时的位置，文件之后移动或删除不会被持续监控。

## 数据位置、卸载和换电脑

- userData固定为 `%APPDATA%\Xiaokaoya\`。
- sessionData固定为 `%APPDATA%\Xiaokaoya\profile\`，IndexedDB底层文件由Chromium管理。
- 已验证本机快照在 `%APPDATA%\Xiaokaoya\backups\`。
- 数据库名XiaokaoyaStudy、origin app://xiaokaoya、默认持久Session、appId及NSIS安装身份保持不变。

Windows“设置 → 应用”可卸载程序，普通卸载保留数据。同一Windows用户重装后继续读取。换电脑、换Windows用户、重装系统或主动清理AppData前，先导出完整JSON并验证能预检，在新环境安装后恢复。不要把运行中的IndexedDB底层文件拷贝当作一致性备份。

开发工具可能处于Windows应用隔离环境，即使显示相同AppData路径，也可能读到工具隔离副本。自动化测试仅使用项目隔离profile，正式验收请亲自从桌面图标启动。

## 第四阶段人工验收

1. 从桌面打开0.4.0，核对原来的年度科目、任务、资料、进度和伙伴保留。
2. 打开学习日历，切换年/月/周/日；定位2028-02-29和2027-12-31，检查闰日和跨年周一开头。
3. 设置本周总目标18小时，选择两科分配6小时、8小时，保存重开仍在；安排某天2小时、另一天3小时，确认每天不同也能保存。
4. 新建一条未定日期的复习测试任务，在待安排池找到；安排日期后确认当天出现，预计时间相应变化。
5. 把同一任务延期到另一日，检查原日期不再显示此任务，新日期只出现一次，安排记录保留原日期和说明；实际时长保持不变。
6. 创建一条过去日期的待完成测试任务，确认待安排池能看到，同时原日历仍保留，重开不自动改为今天。勾选完成后默认池不再展示。
7. 为测试科目维护报名/考试日期，确认日历提醒及年度档案考试日期一致，三个考试状态没有自动变化。
8. 导出V4完整JSON，预检同一份提示一致，检查新增四类CSV；退出后从桌面重开，核对本周目标、未定日期任务和日期历史。正式恢复替换测试请先保留完整JSON。

本版没有提前开发任务倒计时、陪伴计时、伙伴动画音效或扩充语库。第四阶段人工验收并确认后再进入第五阶段；第一期仍为阶段1—7，阶段8负责错题、模拟考试、历年报告和长期验证。
