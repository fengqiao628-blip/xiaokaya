# 小考鸭第三阶段验收报告

日期：2026-11-14。版本0.3.0，数据库V3，完整备份格式1。第二阶段已由用户验收通过；本次仅开发第三阶段。

## 已交付功能

- “我的科目”提供年度档案，按年份、CPA/税务师筛选，保留暂停及归档历史。12科仍由用户自主选择，综合试卷一/二为内部子项。
- 学习、报名/参考、考试结果三个维度独立设置；已通过不会自动改为正在学习、已报名或已参加。
- 周期归档和恢复保留原状态、任务、资料和进度；调整其他选科也不会改写已归档周期。
- 每个年度周期可独立添加教材、视频及版本说明；章节可记录完成情况、1—5星掌握评估和备注。
- 各资料与章节分别记录0—100%进度，教材100%、视频25%、章节未完成、掌握1星可以同时存在。
- 新任务可关联同年度章节，拒绝跨年跨周期关联；综合试卷不匹配的资料不可关联进度。
- 资料和章节提供编辑、归档、恢复，保留历史关联；有进度的资料保留原类型、试卷及版本，换版新增资料。
- 完整JSON覆盖新增四表，恢复预检展示数量；CSV新增资料与章节进度类型，周期CSV增加独立状态列。

## 数据结构与兼容

V1/V2定义保留，V3追加cycleStatuses、materials、chapters、materialProgress，不重写旧业务行。考试状态与原cycles学习状态分开；资料和章节归属固定年度周期；资料章节进度组合唯一。

旧库升级前必须完成全量快照及回读验证，并写prepared日志后才授权版本事务。V1/V2均可直升V3，原子事务异常保留原版本和记录。旧备份按其原schema精确校验，再在内存补齐新表和默认状态；原文件不改动，重复恢复不重复添加。

旧版未完成恢复日志会先按原版本检查或回滚，再进行结构迁移。正式数据路径、origin、Session、数据库名称、appId和NSIS身份不变。第二阶段源码、安装包及ZIP保留在.runtime/baseline/stage-2。
