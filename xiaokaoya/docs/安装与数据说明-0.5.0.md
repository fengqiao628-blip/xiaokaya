# 小考鸭0.5.0 · 安装、升级与第五阶段使用说明

本版交付学习记录、任务倒计时、基础陪伴状态、实际时间确认与重叠检查。Windows x64安装后独立离线使用，无需服务器、账号、Node.js或浏览器地址。保留前四阶段功能。

## 安装及覆盖升级

1. 在旧版“数据与备份”导出完整JSON，保存输入并完全关闭“小考鸭”。
2. 解压ZIP，运行Xiaokaoya-Setup-0.5.0-x64.exe；单独的exe也可直接安装。安装包包含运行环境。
3. 从Windows桌面或开始菜单“小考鸭”图标打开。正式验收统一使用此入口，开发工具可能处于另一份Windows应用隔离环境。
4. 旧库先保存完整升级前快照并回读验证，写入安全日志后才迁移V1—V4到V5。旧业务行保留，新计时工作表初始为空。
5. 核对旧年度科目、任务、资料和伙伴，导出一份新的V5完整JSON。首页按今天日期显示任务；日期从11月14日变为15日后，旧任务仍在原日历日期，不会自动搬到今天。

升级失败会显示错误并保留原库或保护快照，不自动清库。请保留错误和数据目录；不要删除profile，也不要用旧程序强行打开已升级的库。安装程序未签名，Windows可能显示未知发布者，请核对来源及SHA256SUMS-0.5.0.txt。

## 任务倒计时

1. 在首页或学习日历的任务下点击“开始学习”；也可进入左侧“学习记录与计时”→“开启陪伴倒计时”，自由选择年度科目、任务及章节。
2. 选择25/45/60分钟，或填写自定义分钟和0—59秒。总目标支持1秒至8小时，独立于任务预计时长。
3. 点击“开始学习”。界面分别展示倒计时剩余、本次目标和本次有效陪伴；伙伴切换到学习素材状态。
4. “暂停休息”停止累计；“继续本次”从当前时刻重新计，不加入休息间隔。可以关闭计时弹窗查看其他页面，首页保留本次计时入口。切换动物不重置计时。
5. 提前结束点击“结束本段”；倒计时到零也会停止本段，等待你核对，不把之后的等待算作学习。
6. 核对有效片段，填写可选备注，勾选“我已核对有效学习片段，确认保存实际时长”，点击“保存实际时长”。不足1秒可继续或作废。
7. 实际学习保存后，再按实际情况勾选“关联任务已完成”。任务不会因计时到零自动完成；勾选完成也不会再次增加实际时间。
8. “再学一段”保留上一段的科目、任务与章节，重新选择本次目标。每段独立确认保存，同一任务可以累计多段真实学习。

同时只允许一个进行中或待确认的工作计时。切换到其他任务前，请保存或作废本次；暂停仍保留本次工作状态，不释放为第二个并行计时。

确认前不会增加正式学习时长。需要放弃本段时，暂停/结束后勾选作废确认并点击“作废本次”，保留工作记录，实际时间不增加。已保存的学习记录可在“学习记录与计时”中作废。

## 手动学习记录

左侧“学习记录与计时”→“手动记录学习”，选择年度科目，可关联任务与章节，并填写备注。只保留预计时间时不要把它补录为实际时间。

- **填写起止时间**：按北京时间填写实际开始和结束，支持跨零点，最长24小时，不能录入未来时刻。如果中间休息，请分次补录。与已确认的时间或待确认计时重叠时，会阻止保存；首尾相接可以保存。
- **仅填写日期和时长**：填写今天或过去日期、实际分钟数。因为没有起止时刻，软件无法证明是否与其他记录重叠，需要明确勾选没有重复补录的知情确认。此类记录在列表、导出和备份预检中保留说明。

跨零点的起止记录和计时片段按实际学习日拆分。例如23:50至次日00:10会显示两条、各10分钟；属于同一次录入，实际合计20分钟。跨年和闰日同样按真实日期计算。

列表按状态、年度科目和学习日期筛选，每页50条；翻页不改变全量统计、JSON或CSV。无活动计时时界面停止每秒计时刷新，减少长期使用的空闲开销。

更正时间时，先填写说明将错误记录“作废”，再补录正确数据。作废保留原记录及片段，实际统计会扣除；“重新确认记录”重新检查重叠后才计入。原记录内容和最近作废说明可继续查看。不能直接删除历史学习数据。

## 退出、锁屏、休眠与异常恢复

进行中计时每5秒保存可靠检查点；暂停、结束及正常退出会立即尝试保存。倒计时使用墙钟与单调时钟核对，目标时间不会用任务预计值替代。

- 正常退出先完成检查点保存再关闭。保存失败会提示并保留窗口，请处理空间或写入问题后重试。
- 锁屏、休眠以及较长心跳中断会停止计时，解锁/恢复后等待核对；不会自动补算离开期间的时间，也不会自动继续。
- 异常退出或断电保留最近成功保存的检查点，正常运行时通常约有最后5秒尚未落盘。系统卡顿或磁盘错误可能让检查点更早；程序不猜测这段时间。重开后未结束计时进入待确认，用户选择继续、保存或作废。
- 系统时间回拨或大幅变化时，不猜测缺失时间，保留最后可靠检查点。系统时间早于已保存片段时，需要先核对电脑时间再继续。
- 打开“数据与备份”前会将当前计时暂停为待确认，保证预检与恢复期间数据稳定。恢复备份后不沿用原运行时钟，未结束计时要重新核对。

第五阶段只展示本次有效陪伴时间，并将确认的片段计入已有实际学习统计。今日/累计陪伴报告在第六阶段完成；完整动画、声音与语库扩充在第七阶段完成。

## 完整备份、恢复及CSV

“数据与备份”→“导出完整JSON”，包含全部已实现数据、偏好与历史，V5新增工作计时及学习记录来源、章节、备注和作废说明均在其中。建议定期另存到其他磁盘或设备。

恢复流程：选择JSON预检 → 核对版本、数量和警告 → 确认整体替换 → 保存并回读恢复前保护快照 → 单事务替换全部表 → 复核。失败原子回滚或从保护快照还原，异常中断后启动先检查日志。相同内容重复恢复不会追加学习记录。

V1—V4备份按原schema校验，再在内存转换为V5，原文件不改动。恢复是整体替换，没有自动合并；旧备份不含后来增加的学习记录和计时，预检会展示差异，恢复前快照可以找回。备份中的未结束计时恢复后需要核对，不能将导入时刻到当前时刻自动累计。

CSV共十种：学习任务、学习记录、科目周期、学习资料、章节与进度、每周计划、各科周目标、任务安排历史、考试日期提醒、陪伴计时工作记录。学习记录CSV区分手动/计时/历史来源，显示确认状态、实际时间及新元数据；工作记录CSV显示目标、状态和已观察片段，不是一份额外的实际时间总数。CSV供Excel/WPS查看，不能代替完整JSON恢复。

本机日常快照保留最近14份已验证文件；升级前、恢复前、手动快照不自动删除。保护快照失败会阻止操作，日常快照失败会提示。单个文件上限256MB，超出停止，不截断。SHA-256用于检测损坏，不证明文件来源。本机快照不能防止整块硬盘损坏。

## 数据位置、卸载与重装

- userData固定为 `%APPDATA%\Xiaokaoya\`。
- sessionData固定为 `%APPDATA%\Xiaokaoya\profile\`，IndexedDB底层文件由Chromium管理。
- 本机已验证快照在 `%APPDATA%\Xiaokaoya\backups\`。
- 数据库XiaokaoyaStudy、origin app://xiaokaoya、默认持久Session、appId cn.xiaokaoya.study和原NSIS安装身份保持不变。

程序文件与数据库分离。Windows“设置→应用”可卸载程序，普通卸载保留数据；同一Windows用户重装后继续读取。换电脑、换Windows用户、重装系统或主动清理AppData前，先导出完整JSON并验证预检，在新环境安装后恢复。不要把运行中的底层数据库文件拷贝当作一致性备份。

## 第五阶段人工验收顺序

1. 从桌面打开0.5.0，核对旧年度科目、原六条测试任务、19小时周目标、教材进度和伙伴保留。日期切换后可在11月13—16日查看旧任务。
2. 对一个测试任务开始10秒或1分钟倒计时，暂停后等待再继续；确认暂停时有效时间不增加，更换伙伴不重置。
3. 到零后检查任务未自动完成、实际时间尚未增加；核对保存后实际只增加本次有效时长，再勾任务完成不再增加。
4. 手动填写过去的起止时间补录20分钟，预计仍保持原值；再尝试录入交叉时段，确认被阻止且输入保留。仅时长方式检查知情提示。
5. 检查跨零点拆为两日、作废扣除实际且记录保留、重新确认前检查重叠。
6. 计时中正常关闭，从桌面重开应待确认、没有自动补算；可自行锁屏/休眠后检查暂停。真实硬断电不作为人工测试步骤。
7. 导出V5完整JSON并预检同一文件，检查学习记录及计时工作记录CSV；关闭重开后核对数据。运行中的计时会先暂停，因此应在状态稳定后比较同一备份。

阶段验收后才进入第六阶段。本版不加入云同步、账号或多设备冲突处理；第一期仍为阶段1—7，阶段8负责错题、模拟考试、历年报告与长期验证。
