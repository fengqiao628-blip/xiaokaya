# 小考鸭0.7.2 · 安装、升级、卸载与数据备份

Windows x64桌面应用。正式使用不需要服务器、账号、云数据库、浏览器地址、Python或大模型环境，安装后可独立离线运行。第一期仍为阶段1—7，阶段8的错题、模拟考试、历年冻结报告及长期验证尚未开始。

## 安装与升级

1. 旧版用户先在“数据与备份”导出完整JSON到桌面或其他磁盘，保存输入并完全关闭“小考鸭”。
2. 解压Xiaokaoya-0.7.2-Windows-x64.zip，运行Xiaokaoya-Setup-0.7.2-x64.exe。安装包已包含运行环境和Serena音频，不需要妹妹另外下载声音或模型。
3. 使用原Windows账号覆盖更新原安装。安装结束不自动打开程序，请从原桌面或开始菜单“小考鸭”图标启动。
4. 左下角“关于与数据”应显示v0.7.2。先核对原有科目、任务、学习记录及统计，再试听。
5. 0.7.1升级到0.7.2仍为数据库V6，不新增表、字段或迁移；内置语音保存在程序资源中，学习数据继续保存在原用户目录。
6. 若直接由V1—V5升级，程序仍先保存并回读保护快照，验证后再迁移至V6。磁盘或校验失败时停止，保留原库，不要手动删库重建。
7. 更新后导出新的完整JSON，再预检同一文件，应显示完整性通过、内容与本机一致。用随包SHA256SUMS-0.7.2.txt核对安装包来源与摘要。

数据库升级成功后，旧0.6.0无法直接读取V6。覆盖旧程序不等于回退数据库；需要回退时保留整个数据目录及升级前备份，使用经过验证的恢复方案。

正式旧数据核对须从Windows原桌面入口启动。开发工具子进程可能继承不同的AppData隔离环境，不能代替正式桌面验收。

## Serena自然女声

用户已选定试听中的Serena：年轻清亮、温暖亲切的中文女声。新版默认选择Serena，默认朗读方式为“关键状态自动朗读”；声音总开关仍优先，原有开关和音量设置继续保留。新安装默认总静音，按需要开启。

1. 打开左侧“学习伙伴”，向下滚动到“声音与动画”，开启“声音总开关”。
2. 在下方“离线语音朗读”中确认声音为Serena，点击“试听一句”。这段试听与用户选中的样音相同。
3. 开始、继续、暂停、到时、主动结束、任务完成和点击回应时各读一次；也可改为仅手动，或关键状态加学习中每5分钟鼓励。
4. 首页“朗读每日一句”、鼓励卡“朗读这句”可手动点读；“停止朗读”立即停止。新一句替换上一句，不积压排队；初次打开、升级、恢复和重开不补读旧事件。
5. 关闭总开关或音量为0时停止全部声音。切换窗口、锁屏/休眠、关闭程序及进入备份操作会取消朗读。
6. 声音选择、语速和朗读方式仅本次打开有效。重开程序或恢复备份后回到Serena、正常语速和关键状态自动朗读；总开关、音量等原有V6设置仍按JSON恢复，不因默认自动模式绕过静音。

语音包覆盖原有120条状态鼓励、200条每日语句和诗词及试听文字。所有音频随安装包提供，本机直接播放；软件不会调用在线语音服务，不上传学习记录或朗读文字。制作音频所用模型与GPU工具只在开发目录，不进入妹妹的安装包。

**自定义或改写的文字**没有自动生成的Serena音频，会明确提示改选Windows系统声音。程序不会悄悄将Serena替换成机械音色。在声音下拉框中主动选择Windows系统声音后，可使用该电脑已有中文声音朗读这些内容。缺少Windows语音组件不影响内置Serena，也不影响学习和计时。

语音播放故障不会中断计时、保存或备份。若无声，检查软件总开关、音量及Windows输出设备，先点“试听一句”；若个别内置音频损坏，可覆盖安装同版本修复程序资源，保留用户数据。

## 伙伴动画与语库

伙伴支持睁眼待机、自然眨眼、学习点头、暂停休息、点击摇摆和完成庆祝。动画默认沿用已有设置；若希望明显动作，在“学习伙伴”把动画改为“开启动画”，点击“保存体验设置”。关闭动画和系统减少动态设置继续有效。

到时只提示本段时间到了；任务是否完成仍由用户勾选。声音、伙伴切换、文字轮换和庆祝不会增加学习时长，暂停与等待时间不计入实际学习；核对保存的记录才进入统计，陪伴时间已包含在实际总时长中。

每日语库200条，状态鼓励120条；收藏、自定义、归档及出处历史继续保留。内置语句身份与正文保持原值。编辑或归档自定义内容不会改写过去展示的正文和出处快照。

## 完整备份、恢复与CSV

“数据与备份”中导出的完整JSON用于恢复全部学习数据、语库、收藏和已保存体验设置。语音音频属于安装资源，不复制到数据库或JSON；重装当前程序即可取得同一语音包。本次声音和模式等临时选择不写入学习数据库。

建议把JSON另存到其他磁盘或设备。先确认导出成功，再用“选择JSON预检”核对完整性和记录数量；同文件内容一致时无需恢复。恢复是整体替换，程序先保存并验证恢复前快照，失败时回滚。恢复后核对科目、任务、记录、统计和声音总开关，再继续使用。

本机每日首次使用保留日常快照；升级前、恢复前及手动保护快照继续保留。它们与数据库在同一电脑，仍应另存外部完整JSON。

CSV保留各业务表及统计导出，适合Excel/WPS查看，不用于完整恢复。陪伴统计仍是实际学习中的子集，不能再与实际总时长相加。

## 数据位置、重装与卸载

- 用户数据目录：%APPDATA%\Xiaokaoya\。
- Electron sessionData：该目录的profile子目录；IndexedDB保存在这个稳定会话目录内。
- 页面origin固定为app://xiaokaoya，scheme为standard/secure；默认持久Session，数据库XiaokaoyaStudy，结构版本V6，JSON格式1。
- appId固定cn.xiaokaoya.study，NSIS GUID固定d0a54531-87fa-48d9-94d0-ef98f93ca48c。

程序目录与用户数据分离，覆盖升级和普通重装只替换程序资源。普通卸载保留用户数据和本机备份；再次安装后使用原Windows账号和原入口打开。不要手动清理上述用户目录或IndexedDB文件。需要迁移电脑时使用完整JSON恢复，原电脑数据和备份先保留。

## 简短验收

从原桌面入口确认版本与旧数据，试听Serena一次，测试开始/暂停和停止、总静音，导出并预检完整JSON。开发回归使用隔离profile；真实扬声器、另一台电脑、物理睡眠/断电和正式数据人工核对以实际验收结果为准，不将模拟测试当成已完成。
