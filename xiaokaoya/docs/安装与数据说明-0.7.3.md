# 小考鸭0.7.3 · 启动每日鼓励版

2026-11-17。仍为第七阶段/V6；第八阶段未开始。安装后独立离线使用，不需要服务器、账号、Python或语音模型环境。

## 每次打开，听一句鼓励

在“学习伙伴 → 声音与动画”开启声音总开关并保留非零音量后，完全退出程序、再从原桌面图标打开。无需开始学习或点击朗读，Serena会自动读一次首页当天的“每日一句”，读完即停，不循环。

每天仍沿用当天已选定的文字，不为了开场另抽一句。同一天多次完全退出重开，每次都可听一次；程序仍在运行时再次点桌面图标、切换窗口、页面刷新、更换每日语句及恢复备份，不会再触发开场朗读。朗读期间若操作学习事件，新状态语音优先，旧语音不会排队补播。

声音总开关关闭或音量为零时不开场朗读；本次启动后才开启声音也不补读。可手动点击首页“朗读每日一句”。总静音、停止朗读、切换窗口、锁屏/休眠、关闭程序和进入备份操作会取消当前或等待中的语音，返回后不重播。后台启动时只在启动就绪的短暂窗口内等待首次前台显示，超时或已取消则保持安静。

每日内置200条语句及诗词已包含Serena录音；当天若选用自定义或改写文字且没有对应录音，会提示可主动改选Windows系统声音，不暗中使用其他音色。原120条状态鼓励和试听资源继续提供，共322段音频；本次不重新生成或增加语音资源。

开始、继续、暂停、到时、结束、任务完成和点击伙伴仍按原关键状态模式朗读，也可选择仅手动或加学习中每5分钟鼓励。声音、语速、朗读方式为本次临时选择，重开/恢复回到Serena、正常语速及关键状态模式；已保存的声音总开关和音量继续保留。

开场朗读只播放音频，不开始倒计时，不完成任务，不新增学习记录或实际时长。音频故障不影响学习、计时与备份。

## 覆盖升级

1. 原版先导出完整JSON到桌面或其他磁盘，保存输入并完全关闭“小考鸭”。
2. 解压Xiaokaoya-0.7.3-Windows-x64.zip，运行Xiaokaoya-Setup-0.7.3-x64.exe，使用原Windows账号覆盖原安装目录。
3. 安装结束不自动启动。从原桌面或开始菜单“小考鸭”入口打开，“关于与数据”显示v0.7.3。核对原科目、任务、学习记录、统计和当天语句。
4. 若原声音已开启，会自动听到每日一句；尚未开启时，先在学习伙伴开启，再完全退出重开体验。
5. 0.7.2→0.7.3数据库仍为V6，无新增表、字段或迁移。完整JSON及原备份/失败回滚逻辑不变。用SHA256SUMS-0.7.3.txt核对随包文件。

正式旧数据核对使用原桌面入口。开发工具子进程可能继承AppData隔离环境，不能代替正式数据验收。不要启动开发profile来判断正式数据是否保留。

若直接从V1—V5升级，仍先保存并回读保护快照，验证后迁移至V6；磁盘或校验失败时保留原库。旧0.6.0不能直接读取V6，覆盖旧程序不等于数据库回退，不要手动清空或替换IndexedDB。
