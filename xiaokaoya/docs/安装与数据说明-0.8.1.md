# 小考鸭 0.8.1：导航页面与思源黑体

2026-11-18，Windows x64 离线桌面版。

## 本次更新

- 点击左侧“我的科目、学习日历、学习记录与计时、学习统计与进度、练习/错题/模拟、学习伙伴、励志语与诗词、数据与备份、关于与数据”，切换右侧内容页。导航选中状态、面包屑和页面标题同步更新。
- 各页采用正常页面滚动，按可用内容宽度调整筛选栏、科目列表、表单、统计卡片和伙伴卡片。窄屏保留可横向滑动的底部导航，表格在各自区域内滚动。
- 新建/编辑任务、年度选科、学习倒计时保留为短操作弹窗，关闭或保存后回到原页面。
- 全局界面改用随程序内置的思源黑体，涵盖正文、标题及表单；安装后离线可用，无需在 Windows 中另外安装。字体版权及 SIL OFL 1.1 许可证随包保留，来源见 [字体说明](../public/fonts/README.md)。

## 安装与升级

1. 保存正在填写的内容，完全退出旧版“小考鸭”。
2. 运行 `Xiaokaoya-Setup-0.8.1-x64.exe`，沿用原安装位置；也可将同版 ZIP 发送到另一台 Windows x64 电脑，解压后安装。
3. 从原桌面“小考鸭”图标启动，在“关于与数据”查看版本。点击左侧各导航，右侧应显示对应页面，不再出现覆盖全窗口的页面弹窗。

程序和学习数据分开保存，普通覆盖升级、卸载不会删除历史记录。数据库仍为 V7，从 0.8.0/V7 升级无需新增迁移；如果原库仍为 V6，首次启动仍执行既有的 V6 保护备份验证及 V7 迁移。V7 无法由旧 0.7.4 直接读取，回退边界与 0.8.0 相同。

正式数据目录仍为 `%APPDATA%\Xiaokaoya\`，持久会话仍在其 `profile` 子目录，origin 为 `app://xiaokaoya`，数据库为 `XiaokaoyaStudy`。测试仅使用项目内隔离目录。

完整 JSON 用于备份与恢复，CSV 用于表格查看；请定期将完整 JSON 保存到另一磁盘或设备。更换电脑通过完整 JSON 迁移个人记录，安装包不包含本机学习数据。
