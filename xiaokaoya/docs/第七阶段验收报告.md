# 小考鸭第七阶段验收报告

日期：2026-11-17。用户已确认第七阶段技术方案，了解V5→V6的原因和回退限制，并明确要求继续开发。程序0.7.0、数据库V6、JSON封装格式1。第一期仍为阶段1—7，阶段8未开始。

## 本阶段功能

- 五位伙伴统一配置：学习/休息状态、眨眼、轻微呼吸、短暂庆祝与点击/键盘回应。真实完成事件庆祝一次；历史开心姿态不在重开时重新庆祝。默认跟随系统减少动态，可保存为开启或关闭。
- 本地合成短音效按开始、暂停、结束、任务完成、到时、点击映射，五位伙伴音色不同。默认总静音，提供音量、伙伴状态音和到时音开关及试听。总关闭立即静音，保存期间的旧快照不能重新启声；静音优先于分项开关。设备异常只提示，不阻断任务、计时或备份。
- 独立120条原创状态鼓励，10类各12条；学习时每5分钟温和轮换，可手动换句。到时、结束本段、任务完成分别提示，文字不自动朗读，不增加实际时长。
- 新库200条每日语句：168条原创鼓励（含旧q1—q8）、14条古典名言、18条诗词节选；分类、搜索、出处详情、收藏、历史、自定义、编辑和归档。每页20条，全库及全部历史进入完整备份。
- 每日一句同日重开/升级保持，主动换句保存；偏好分类只影响下一次选择。自定义编辑或归档不改写以前展示的正文及出处快照。旧历史缺出处时明确说明，不猜作者。

语库与本地素材来源见[语库来源与素材说明](语库来源与素材说明.md)，详细操作见[安装与数据说明-0.7.0](安装与数据说明-0.7.0.md)。全部资源离线随包，不接入服务器、账号、在线朗读或云同步。
