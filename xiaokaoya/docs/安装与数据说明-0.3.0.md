# 小考鸭0.3.0 · 安装、升级与第三阶段使用说明

本版交付第三阶段：年度科目档案、独立考试状态、教材视频及章节管理。无需服务器、账号或网络，Windows x64安装后可离线使用。

## 安装和覆盖升级

1. 保存输入，完全关闭旧版“小考鸭”。
2. 解压ZIP，双击Xiaokaoya-Setup-0.3.0-x64.exe；单独的exe也可直接安装。安装包包含运行环境，无需Node.js或浏览器地址。
3. 从Windows桌面或开始菜单的“小考鸭”图标打开。正式验收统一使用该入口，避免开发工具的Windows应用隔离环境读取另一份数据。
4. 首次打开旧库时，程序先一致性读取并保存完整升级前快照，写入及回读验证成功后才迁移V1/V2→V3。旧表逐行保留，新增四张表。
5. 升级后核对原有任务、年度和伙伴，并导出一份新的完整JSON。旧周期默认“未计划报考”“考试结果未记录”，不会根据学习状态推测已报名或已通过。

升级失败会保留旧库或保护快照并显示错误，不自动清库。不要删除profile或用旧程序强行打开已升级的数据库。本版本未签名，系统可能显示未知发布者；请核对来源和SHA-256。

## 我的年度科目档案

点击左侧“我的科目”，选择年份、考试分类和具体科目。不同年份使用独立周期；新建年度不会复制或覆盖旧年度的教材、章节、进度或考试结果。

“调整年度选科”保留12科自主选择，取消勾选会暂停该年度科目，不删除任务或资料。CPA综合测试仍只有一门一级科目，试卷一、二作为内部子项。

周期详情分别设置学习状态、报名与参考状态、考试结果、可选考试日期和备注。通过、报名、参加考试都不会自动修改其他状态。保存后重新打开检查。

归档周期需勾选确认。归档后历史数据继续保存，勾选“显示已归档周期”可查看并恢复；恢复周期保持原有状态，暂停状态也不会自动变成正在学习。

## 教材、视频与章节

1. 在目标年度科目下“添加资料”，选择教材或视频，填写名称及版本说明。综合科目可选择试卷一、二或全科通用。
2. “添加章节”，记录章节名称、独立的章节完成情况、1—5星掌握评估（也可尚未评估）和备注。
3. 在章节中“记录资料进度”，选择对应教材或视频并填写0—100整数百分比。同一章节可以分别记录多个资料的进度。
4. 教材学到100%不会自动完成章节或提高星级；完成章节也不会自动把视频进度改成100%。
5. 资料和章节仅属于本年度科目，不能移动到其他年度。试卷一、二不匹配的资料不能用于对应章节。
6. 新任务可选择同年度科目的章节。归档章节不删除原任务的关联，但不会用于新任务。

资料或章节可以编辑名称、归档及恢复。已有进度的资料不能改类型、试卷和版本；需要新版时新增资料并归档旧版。已被任务或进度引用的章节保留原试卷关联。

## 备份、恢复与CSV

“数据与备份”导出完整JSON，包含已实现的全部数据、偏好及历史。V3新增考试状态、资料、章节和资料章节进度均已纳入完整清单。

恢复顺序仍为：选择JSON预检 → 查看当前与恢复后的数量、警告 → 勾选整体替换 → 先保存并验证恢复前快照 → 单事务替换所有表 → 复核。失败原子回滚或补偿还原；异常中断后启动先检查日志。

V1/V2备份可在内存中转换为V3，原文件不变。旧备份不包含后来新增的资料章节，整体恢复会以其内容替换当前数据；数量差异会显示，恢复前快照可以用于找回。没有自动合并功能。重复恢复相同内容不会追加记录。

CSV可分别导出任务、学习记录、科目周期、学习资料、章节与进度。科目周期CSV包含三个独立状态；章节CSV分别列出完成情况、掌握星级和各资料的学习百分比。CSV用于查看，不能代替完整JSON恢复。

本机日常快照保留最近14份已验证文件；升级前、恢复前及手动快照不自动删除。每日快照失败会提示，重要操作的保护快照失败会阻止操作。单个文件上限256MB，超出明确停止，不截断。SHA-256用于发现损坏，不证明文件来源。

请把完整JSON定期另存到电脑之外的设备，本机快照不能防止硬盘损坏。导出回执只记录成功时的位置，不保证文件之后没有被移动或删除。

## 数据位置、卸载和重装

- userData：%APPDATA%\Xiaokaoya\。
- sessionData：%APPDATA%\Xiaokaoya\profile\，由Chromium管理IndexedDB底层文件。
- 本机快照：%APPDATA%\Xiaokaoya\backups\。
- 数据库名称XiaokaoyaStudy、origin app://xiaokaoya、默认持久Session和安装身份继续固定。

程序和数据分离，普通卸载保留数据。相同Windows用户重装后继续读取；不要额外删除profile。换电脑、换Windows用户或重装系统前先导出完整JSON，在新环境预检恢复。不要把运行中的底层数据库文件拷贝当作一致性备份。

## 第三阶段人工验收

1. 确认显示0.3.0，旧任务、年度和伙伴仍在。
2. 在2027年会计中分别设置学习状态、报名状态和考试结果，检查互不替代。
3. 新增/查看2028年同科，确认状态与资料独立，返回2027年旧记录仍在。
4. 添加测试教材和视频，以及一个章节：教材进度100%、视频25%、章节未完成、掌握1星，确认四者独立显示。
5. 新建任务关联章节，归档并恢复周期/章节，确认旧任务和进度保留。
6. 导出V3完整JSON，预检同一份应提示一致；CSV检查新增列；完全退出并从桌面重开检查数据。

先使用测试资料验收。计时器、陪伴时长、动画音效和丰富语库仍按第五至七阶段开发，未在本版提前交付。阶段验收并确认后再进入第四阶段。
