# 小考鸭0.7.0 · 安装、升级、卸载与数据备份

Windows x64桌面应用。安装后可在本机独立离线运行，无需账号、服务器、云数据库、Node.js或浏览器地址。第一期范围为阶段1—7；错题、模拟考试、历年冻结报告与长期验证继续留在阶段8，云同步及多设备冲突处理未加入。

## 安装与升级

1. 旧版用户先在“数据与备份”导出完整JSON，保存到桌面或其他磁盘，再保存输入并完全关闭“小考鸭”。
2. 解压`Xiaokaoya-0.7.0-Windows-x64.zip`，运行`Xiaokaoya-Setup-0.7.0-x64.exe`。安装程序已包含运行环境，不需要另装开发工具。
3. 覆盖升级使用同一个Windows账号和原安装入口。安装结束不会自动打开程序，请从原桌面或开始菜单“小考鸭”图标启动。
4. 左下角“关于与数据”应显示`v0.7.0 · 第七阶段验收版`。
5. 第一次从V1—V5升级时，程序先保存旧版本完整保护快照并回读验证，才进行V6迁移。磁盘不足、文件校验失败或迁移事务失败时会停止，保留原数据；不要手动删库重建。
6. 核对旧科目、任务和学习统计。已有21分钟实际、其中1分钟陪伴的验收样例，升级后仍应是21/1分钟；后续新增记录按实际变化。
7. 重新导出一份完整JSON，再预检同一文件，应显示完整性通过、内容与本机一致。

程序与数据分离，安装包不包含开发或测试学习数据。更新保持原appId、NSIS身份、origin、Session、数据库名称和数据目录；只替换程序。Windows可能对未签名安装程序显示未知发布者，请核对发送来源及随包SHA256SUMS-0.7.0.txt。

**数据库升级成功后，旧0.6.0不能直接读取V6。重新安装旧版不等于回退数据库。** 如需回退，请保留整个数据目录和升级前V5完整JSON，按经过核验的恢复方案处理；不要用旧程序强行打开V6，也不要覆盖IndexedDB文件。

正式验收从Windows原桌面入口启动。开发工具启动的子进程可能继承另一份AppData隔离环境，不能用它替代正式用户数据验收。

## 伙伴动作与小声鼓励

五位伙伴均有学习、休息、回应和短暂庆祝。点击首页或倒计时中的伙伴可以打招呼；切换伙伴不会改变任务、计时片段或学习时长。

“伙伴的小声鼓励”有独立的120条原创文案，10种状态各12条：准备、开始、持续专注、暂停、继续、到时、结束本段、任务完成、今日目标完成及点击回应。专注时每5分钟温和换句，也可手动点击换句图标。状态文字不覆盖每日一句，不增加学习时间，也不自动朗读。

到时提示只表示本段时间到了；结束本段只肯定投入。任务是否完成仍由你自己勾选。暂停和等待时间不计入，实际时长核对保存后才进入统计，陪伴已包含在实际总时长中。

## 声音、音量与动画

打开左侧“学习伙伴”，在伙伴选择下方找到“声音与动画”：

- 声音总开关默认关闭。开启后可试听伙伴音效或到时提示；各动物使用不同的本地合成短音色，不联网下载声音，也不会持续循环叫声。
- 总开关单独即时保存；关闭时立即停止声音。音量0—100、伙伴状态音效、到时提示、动画及每日分类偏好调整后，点击“保存体验设置”。
- 可只保留到时提示，也可全部静音。音量为0同样不播放。
- 动画默认跟随系统减少动态设置，可选择开启动画或关闭动画。
- 声音设备或素材异常不会阻断计时与保存；无法试听时可检查系统音量和输出设备，继续正常使用学习功能。

设置保存在本机，关闭重开后保留；完整JSON也包含这些设置。恢复备份后使用备份中的偏好，不重播过去的到时或完成事件。

## 每日一句、名言与诗词

左侧“励志语与诗词”或首页“打开励志语库”进入语库。新库包含200条：168条原创鼓励（含保留的原8条）、14条古典名言、18条诗词节选，与120条状态鼓励独立。

- 支持按文字、作者或作品搜索，并按分类、类型筛选；每页20条。
- “查看出处详情”显示作者、作品、原文来源及链接文字。所需内容已在本地，查看不需要网络。古典文本为公有领域原文节选，不复制现代译文；具体核对来源保存在开发文档与程序中。
- 点击“收藏”后在“我的收藏”查看，取消收藏不删除语句。
- 点击“设为今日一句”或首页换句后保存当天选择；同一天刷新、关闭重开及软件升级保持已选语句。
- “每日一句偏好分类”只影响下次选择，不改写今天已经保存的一句。
- “添加自定义语句”可保存自己的正文、分类与选填的作者、作品、出处。署名标明“用户填写”，不冒充核实过的名言。
- 自定义内容可以编辑。修改、归档或取消收藏不会改写过去展示过的正文和作者出处；旧版历史未保存作者时会如实说明。
- “归档语句”使它退出之后的选择，历史和收藏仍保留；勾选“显示已归档语句”可恢复使用。至少保留一条可用语句。

## 完整备份与恢复

“数据与备份”→“导出完整JSON”，选择profile之外的位置，如桌面、其他磁盘或U盘。完整JSON包含已实现的全部数据表：学习档案、任务、教材章节、计划、日期历史、实际学习和片段、工作计时、语库、每日一句与历史、作者出处、收藏和声音/动画设置。

建议每周或重要录入后导出，并另存到其他磁盘或设备。安装包ZIP不能代替学习数据备份；CSV用于表格查看，不能用于完整恢复。

恢复步骤：

1. 先导出当前完整JSON。
2. 点击“选择JSON预检”，选中要恢复的备份，检查版本、完整性、数量和差异。
3. 相同内容会提示无需恢复，不追加重复记录。
4. 恢复采用整体替换，不能自动合并。确认来源与时间后勾选替换确认，再点击“先备份，再恢复”。
5. 程序先保存并回读当前整库保护快照，然后事务写入并复核；失败保持或回滚当前数据。若无法确认一致会停止后续写入，保留原库、日志和快照。
6. 恢复后统计重新从确认记录计算；未结束计时保留待核对，不自动继续或补算。

V1—V5旧JSON会先按原schema预检，再在暂存区转换为V6。新增收藏为空、体验偏好默认静音，原文件不改动；恢复后的内容以预检数量为准。V6备份按其原内容恢复，不暗中合并其他语库或当前本机数据。

既有十类原始CSV和统计三页的当前范围CSV继续保留，中文表头可用Excel/WPS打开。时间单位明确，公式符号开头的自定义文字经过保护，取消或导出失败不改变学习记录。

## 固定数据位置

- userData：`%APPDATA%\Xiaokaoya\`。
- sessionData：上述目录的`profile\`子目录；IndexedDB实际存储在此会话目录内。
- 本机保护快照：userData内的`backups\`；可从“数据与备份”打开。
- 页面来源：`app://xiaokaoya`，standard、secure；默认持久Session。
- 数据库：`XiaokaoyaStudy`，本版结构V6，JSON封装格式1。
- appId：`cn.xiaokaoya.study`；NSIS GUID：`d0a54531-87fa-48d9-94d0-ef98f93ca48c`。

每日首次使用自动保存快照，保留最近14份日常快照。手动、恢复前和升级前保护快照不自动删除。同一磁盘内快照不能防整盘损坏，因此仍需外部JSON备份。

## 卸载与重装

先导出并验证完整JSON，再在Windows“设置→应用→已安装的应用”卸载“小考鸭”。普通卸载保留用户数据目录；用兼容V6的版本重装后，在同一Windows账号下可继续读取。

若想彻底清除学习数据，应由本人另行明确操作并先验证外部备份；普通卸载不会替你删除profile或历史记录。不要在程序运行时复制、移动或删除IndexedDB目录。

## 第七阶段简短人工验收

主要流程由开发者自动测试。更新后只需核对：版本为0.7.0、旧数据保留；伙伴有动作且可关闭；开启试听能听到短音效，总静音后不再发声；语库可以收藏和保存自定义；完整JSON导出并预检一致。测试声音时可先调低系统音量。

另一台物理电脑、妹妹电脑、干净虚拟机、整机真实断电或真实睡眠尚不等于自动测试已覆盖；验收报告会如实列明环境边界。第七阶段验收确认后才进入阶段8。
