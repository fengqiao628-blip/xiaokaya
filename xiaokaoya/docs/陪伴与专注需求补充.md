# 陪伴与专注需求补充

记录日期：2026-11-14。第二阶段已验收通过。第三阶段开始前，用户补充丰富励志语、伙伴状态音效和任务倒计时陪伴的需求。本文件记录后续实施范围，不代表这些功能已经交付；本次不修改程序或数据库。

## 励志语与诗词

- 扩充本地语库，包含原创鼓励、名人名言、古典诗词，以及专注、坚持、休息、考前等分类。首批建议以约200条为目标，质量优先，后续可扩充。
- 名人名言和诗词标注作者、作品或可核对出处；实施时逐条核实，不使用归属存疑的条目。
- 保留分类、收藏、历史和自定义需求。诗词使用合适的短句，长内容可查看详情。
- 每天固定一句，同一天刷新、重开保持一致；主动换一句后保存当天选择。任务状态触发的动态鼓励另行显示，不覆盖固定的每日一句。
- 全部内置资源离线可读；升级扩充默认库时按稳定ID增量加入，保留用户自定义、收藏、历史及已分配的每日语句。

## 伙伴动画与声音

2026-11-16补充：伙伴“小声鼓励”须跟随准备、开始、专注、暂停、继续、到时、结束本段、任务完成、当天目标完成及点击回应变化，每类至少12种文案，独立于每日一句。例：“坚持就是胜利”“辛苦了，今天的你也很棒”。学习中最多每5分钟温和换句，也可主动换句；同类轮换减少重复。到时不等于任务完成，结束本段只肯定投入。文案不自动朗读，不改变学习记录与任务状态。已纳入第七阶段方案。

- 延续鸭、猫、熊、兔、狗的独立素材与配置。动作可包括眨眼、轻微呼吸、学习、休息、短暂庆祝和点击回应；各动物使用同一套事件接口。
- 配置可选的专属短音效，映射开始学习、暂停休息、完成任务、倒计时结束、点击回应等事件。新增动物只补素材与配置，不按动物名称增加业务分支。
- 建议默认静音，提供总开关、音量及伙伴音效/到时提示选择；关闭总开关后保持静音。状态事件只触发一次，避免反复播放或学习中持续发声。
- 提供关闭动画和减少动态效果的方式。声音/动画失败不影响计时、任务保存或备份；全部素材随安装包提供，离线可用。
- 切换伙伴不改变任务、学习记录、计时进度或累计有效学习时长。

## 任务倒计时与学习陪伴

基本流程：任务卡点击“开始学习” → 选择25/45/60分钟或自定义 → 开始倒计时并切换伙伴学习状态 → 暂停、继续或结束 → 核对有效时长 → 自行勾选任务完成。

- 展示本次剩余时间与实际专注时间；本次倒计时目标与任务预计时长独立，可参考预计值但不将其当作实际时长。
- 暂停时伙伴休息，暂停时间不计入有效时长。倒计时结束后给出视觉提示，可按设置播放一次短音效，允许休息、继续学习或勾选完成。
- 到时停止本段学习计时，等待用户选择后才开始下一段，避免把无人操作的等待时间记入学习。
- 倒计时到零不自动判定任务完成；提前完成任务时可结束本段并确认实际学习时长，保留原预计值。
- 实际时长只来自有效学习片段，经确认后进入正式统计。多次“继续学习”可关联同一任务的多段学习，不能因勾选完成、重复点击、重开页面而重复累计。
- 同时只允许一项活动计时，切换任务时先暂停或结束当前计时，并检查时间重叠。
- 电脑锁屏、睡眠时暂停；正常退出先保存计时状态；异常关闭或恢复备份后显示待确认记录，不静默补算或自动继续。
- 本次陪伴计时由同一组学习片段推导，不额外建立一份反复相加的时长总数。今日/累计陪伴汇总以确认的陪伴计时记录计算，并与含手动补录的全部学习时长清楚区分。
