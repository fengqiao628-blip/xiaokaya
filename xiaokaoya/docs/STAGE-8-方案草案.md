## 练习与错题

练习记录保存年度科目、日期、可选章节、来源、总题数、答对/答错/未答数及备注；错题保存手工录入的题干、选项、答案、解析、错因、标签和复习记录。可以只收录部分错题，所以统计以已确认的练习记录为准，不从错题本条数反推正确率。

练习正确率分母采用已作答题数，未记录或分母为零时显示无记录。复习日志保留当时的题目/答案快照，后续编辑题干不会改写过去的复习事实；掌握情况由用户标记，不根据学习时长自动判断。

## 模拟考试

支持用户创建模拟考试，保存年度科目、试卷名称、日期、时限、题目/得分及备注。分数与满分由用户维护，空值与0分区分，不把缺失数据展示成0分。

使用现有单活动计时及学习片段机制：暂停不计时，到时停止，不自动判定考试通过。确认后的实际学习记录与模拟考试建立引用；考试页面只展示这份时间，不再另加一次时长。模拟成绩不自动改动独立考试结果或学习状态。

## 历年冻结报告

用户主动生成报告，保存生成时的年度范围、版本、来源记录指纹及汇总快照；已有报告保持生成当时的事实。后续补录或作废记录后，可生成新版本，并保留旧报告及说明。

报告区分学习时间、陪伴子集、练习正确率、模拟成绩、当前掌握评价及缺失数据。年份不自动滚动，上一年的任务、档案和报告不会因新年被覆盖。没有历史事件的数据不能补造历史状态。

## 拟议数据结构：V7

当前V6没有练习、错题、模拟考试或冻结报告的存储结构。拟保持已发布V1—V6定义及原业务行不变，在V7增加以下6类记录；最终字段及索引随实施方案确认，当前不写入数据库。

| 拟新增表 | 用途与关键关联 |
|---|---|
| practiceSets | 练习批次、计数与日期，关联原年度科目/可选章节/确认的学习记录 |
| mistakeItems | 错题内容、错因及手动掌握状态，关联可选练习批次 |
| mistakeReviews | 复习结果与当时内容快照，关联错题，保留历史 |
| mockExams | 模拟考试、时限/成绩及状态，引用原计时和确认学习记录 |
| mockExamQuestions | 模拟考试题目、作答与得分，关联考试和可选原章节 |
| reportSnapshots | 按年度保存版本化报告、指标快照与来源指纹 |

新增数据具有独立ID及校验规则。新表引用已归档周期时仍能查看历史；不复用任务备注承载结构化错题，不向原表写入无法解释的占位值。

## 调整原因与风险：实施前需确认

1. **需要V7承载新增数据。** 新表及关联会影响完整备份、预检和恢复；遗漏新表会导致恢复不完整。所有新表必须同时纳入完整JSON、引用校验和失败回滚。
2. **升级后旧0.7.4不能直接读取V7。** 升级前保存并回读验证V6保护快照，事务内建表/校验，失败保持原库。升级成功后回退必须使用保留的V6备份与受验证恢复方案，不能仅覆盖安装旧程序。
3. **报告与题目快照增加体积。** 当前完整JSON读写上限为256MB；先测实际体积和内存开销，保持原限制。若未来确需调大限制、分卷或外置附件，必须另行说明原因及风险后确认，不静默改变备份策略。
4. **模拟计时可能重复统计。** 只引用现有确认的学习记录和片段，复用去重/重叠检查，不新建可反复累加的计时总数；未确认或已作废的记录不进入实际时长。

继续固定userData=%APPDATA%\Xiaokaoya\、sessionData=其profile子目录、standard/secure的app://xiaokaoya、默认持久Session、XiaokaoyaStudy数据库名、appId及NSIS GUID。云同步与多设备冲突不纳入本阶段。
