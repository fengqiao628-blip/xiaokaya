# 小考鸭 0.1.0 · 第一阶段测试版

本版本用于测试，请只填写测试任务。第二阶段的完整 JSON 备份、恢复、迁移及失败回滚通过验收后，才开始正式积累长期记录。

## 安装与使用

1. 将 ZIP 下载到电脑并解压；不要直接从压缩包内运行。
2. 双击 `Xiaokaoya-Setup-0.1.0-x64.exe`。默认安装到当前 Windows 用户，不要求安装 Node.js 或开发工具。
3. 从桌面或开始菜单的“小考鸭”打开。安装和运行所需程序、字体依赖与插画均在本地，无需服务器或登录。
4. 先选择 CPA / 税务师科目与年份，再创建学习任务。选择可以留空，取消选择会暂停该年度科目，保留已有任务。
5. 任务完成不会自动增加实际学习时长。本阶段没有学习记录录入或计时器，累计实际时长显示真实的零记录状态。
6. 在“学习伙伴”切换动物；每日一句同日刷新不变，手动切换后也会保存。

目前提供 Windows x64 安装包。未做 ARM 或 Windows 7/8 兼容承诺。本版本未签名，Windows 可能显示未知发布者；请核对发送者、版本及 SHA256，不要关闭系统防护。

## 程序和数据的位置

正式安装版：

- userData：`%APPDATA%\Xiaokaoya\`
- sessionData：`%APPDATA%\Xiaokaoya\profile\`
- IndexedDB 在上述 profile 内由 Chromium 管理；不是可单独复制的一份 SQLite 文件。
- 开发/自动化测试版使用项目 `.runtime` 下的隔离目录，不读取正式数据。
- “关于与数据”展示当前实际目录，并可打开数据文件夹。

请勿移动、删除 profile 或将运行中的 IndexedDB 底层文件当作一致性备份。

## 重装、升级和卸载

- 同一 Windows 用户下，普通卸载保留数据目录；重装后继续读取原数据。
- 升级需先关闭小考鸭，再安装新版完整安装包。固定 appId 和安装 GUID 用于识别同一应用。
- 第一阶段只验证同结构的重装与覆盖升级。涉及数据库结构迁移的新版本，必须经过第二阶段迁移/恢复验收。
- 不要用旧程序强行打开新版数据库；不能假定 Chromium profile 支持任意降级。
- 在 Windows“已安装的应用”中卸载小考鸭。卸载只移除程序；不要额外手动删除 AppData 数据目录。
- 换电脑、换 Windows 用户或重装 Windows，不会自动带走数据，需要完整 JSON 备份恢复功能。

## 备份说明与本阶段限制

本阶段尚未交付 JSON 导出、恢复、CSV 导出及自动快照，界面也没有虚假的备份按钮。

第二阶段将提供一致性 JSON 导出、导入预检、恢复前自动文件快照、失败回滚、旧版本迁移和 CSV 导出。到时应在升级或换电脑前把完整 JSON 保存到独立磁盘/设备，并定期验证恢复。正式使用说明会随该阶段更新。

本地自动快照不能代替电脑之外的备份，单纯卸载保留数据也不能防止硬盘故障或手动删除。
