# 小考鸭0.6.0 · 安装、升级与第六阶段使用说明

本版新增首页今日/累计陪伴、学习时间统计、独立进度和每周总结。Windows x64安装后可独立离线使用，无需账号、服务器、Node.js或浏览器地址。保留前五阶段功能。

## 安装与覆盖升级

1. 在旧版“数据与备份”导出完整JSON，保存输入，完全关闭“小考鸭”。
2. 解压Xiaokaoya-0.6.0-Windows-x64.zip，运行其中Xiaokaoya-Setup-0.6.0-x64.exe。单独的exe也可安装，安装包包含运行环境。
3. 从Windows桌面或开始菜单原来的“小考鸭”图标打开；点击左下角“关于与数据”，名称下方显示v0.6.0。
4. 从0.5.1升级时数据库继续V5，无需迁移或重建。原学习记录、计时工作记录、周期、教材章节、周计划和偏好保留。更早的V1—V4库继续走已有的保护快照、验证及迁移流程。
5. 核对旧科目和任务。在“学习统计与进度”选择“时间统计”→“全部”，查看全历史实际与陪伴时间，再导出一份完整JSON。

程序与数据分离；普通覆盖安装不会替换用户profile。不要手动删除profile，也不要用更早程序强行打开它不支持的数据库。安装程序未签名，Windows可能提示未知发布者；请核对来源与SHA256SUMS-0.6.0.txt。

正式验收统一从原Windows桌面入口打开，开发工具启动的程序可能继承另一份AppData隔离环境。更新安装结束后不会自动启动程序。

## 首页陪伴时间

首页新增“今日陪伴”和“累计陪伴”。它们只来自已确认保存的计时来源学习记录，已经包含在“累计实际学习”中。手动补录单独计算，不能再把陪伴加一次。

例如1分钟陪伴计时加20分钟手动学习：实际21分钟，陪伴1分钟。未确认计时、暂停、关闭期间、待核对及作废记录均不增加实际或累计陪伴。工作记录CSV可以包含已作废测试计时，但不代表它已进入实际学习。

## 时间统计

左侧“学习统计与进度”→“时间统计”：

- 选择日、周、月、自然年或全部；每周从周一开始。定位学习日期及左右箭头可查看不同时间。
- 考试分类、备考年份和年度科目可组合筛选。**备考年份与学习发生日期不同**：2026年为2027年备考的记录，在2026自然年学习时间中；选择2027备考年份可以查看该周期各年的学习。
- 默认包含已归档科目，暂停科目也保留。取消“包含已归档科目”只调整当前统计范围，不删历史。
- 实际、其中陪伴、预计安排和任务完成分别展示。预计来自任务当前安排；已取消和未定日期任务不进入日期范围。任务完成不会把预计时长加到实际。
- 趋势图按来源分色，虚线柱是预计。点击年/月/日期可逐级查看；“查看趋势数据表”提供分钟明细。
- 学习日和连续天数只按实际时长大于0的日期计算。当前连续学习截至今天；今天未学习时可接续昨天。范围内最长连续只看所选范围。

“本周”仅统计本周发生的学习，并非累计。验收已有21分钟记录时，选择“全部”再核对；如果20分钟在上周，本周不会把它重复算进来。

## 学习进度

“学习进度”展示当前档案，不随之前的学习日期范围切片，也不是某个过去日期的进度快照。

- 教材和视频按资料、版本逐份显示。每份资料对适用章节等权平均，未记录章节按0参与，同时显示“已记录/适用章节数”。没有适用章节时显示暂无，不伪造百分比。
- 综合阶段试卷一、二仍是内部子项，资料只使用兼容试卷的章节。共有未分试卷章节可兼容。
- 章节完成率、掌握星级分别展示；未评分不按1星计算。教材100%不会自动把章节变为完成或5星。
- “包含已归档资料与章节”可回看旧版本。时间统计不会因为资料归档而消失。
- “到年度档案更新”可打开对应年度科目，继续使用原有编辑、保存和错误处理。统计页本身不改进度。
- 资料每页20份、章节每页50章；分页只减少当前渲染，汇总与导出仍含全部记录。

练习数量、正确率、错题及模拟考试仍按第八阶段实施，不把未实现的内容显示成0%正确率或0分。

## 每周总结

选择“每周总结”，定位该周任意一天，即可查看周一至周日：实际与陪伴、预计安排、已完成任务、学习日、上周实际对比、未完成任务、相关章节和调整参考。

全科总目标保留原周计划；筛选科目后的目标使用已设置的各科分配，不把全科总目标复制给每一科。没有明确设置的历史目标显示未设置。各科分配与全科目标可以独立调整。

总结根据现有记录实时生成，补录、作废和任务改期会更新结果，不是冻结报告。现有数据没有章节完成事件历史，因此“本周关联章节（当前状态）”表示本周任务/学习关联章节现在的状态，不表示都在本周首次完成。第八阶段再实施历年报告与长期验证。

“调整本周学习安排”打开相应周日历。总结和建议不会自动移动任务、修改目标、切换科目或改变考试状态。

## CSV、完整备份和恢复

统计页底部“导出当前统计CSV”导出当前页及筛选范围。时间统计按秒导出，进度标注当前状态，周总结保留周区间和科目范围；可用Excel/WPS打开，取消或失败不改学习数据。CSV防止把以公式符号开头的自定义文字作为公式执行。

“数据与备份”原十类原始数据CSV继续保留。统计CSV是派生结果，**完整恢复必须使用JSON**。

完整JSON包含所有已实现表和记录；第六阶段没有新增持久统计表。导入前验证摘要、版本、数量和外键，再显示差异；恢复前自动保存并回读保护快照，失败回滚。相同内容不会追加记录。V1—V4旧备份按原schema预检并在暂存区转换，原文件不改动。

恢复是整体替换，不自动合并。恢复后统计从原记录重新计算；未结束计时仍须核对，不自动补算。新旧记录数量不同通常说明选取了不同时间导出的备份，应先看预检，保留当前完整备份。

## 数据位置与日常备份

固定身份保持：appId cn.xiaokaoya.study；NSIS GUID d0a54531-87fa-48d9-94d0-ef98f93ca48c；origin app://xiaokaoya（standard、secure）；默认持久Session；数据库XiaokaoyaStudy。

- userData：`%APPDATA%\Xiaokaoya\`。
- sessionData：上述目录的`profile\`子目录；IndexedDB随固定origin和Session保存在其中。
- 本机JSON快照：userData内`backups\`；“数据与备份”可打开。
- 每日首次使用自动快照，最近14份日常快照轮替；手动、恢复前和升级前保护快照不自动删除。
- 建议每周或重要录入后导出完整JSON，并另存到其他磁盘、U盘或设备。只放本机同一磁盘不能防整盘损坏。

普通卸载保留用户数据，重新安装后可继续读取。卸载前建议先导出完整JSON。若主动彻底清除数据，应先验证外部备份并由本人明确操作，程序不会自动删除历史profile。

## 第六阶段简短人工验收

主要流程已自动测试，正式桌面仅需核对自己的数据：

1. 从桌面打开v0.6.0，首页累计实际仍为21分钟，累计陪伴1分钟，旧任务/科目/资料保留。
2. 打开统计，选择“全部”，应显示实际21分钟、陪伴1分钟、手动20分钟。切换“周”时按真实日期分周显示；默认周一开始。
3. 在“学习进度”选择对应年度科目，教材、视频、章节完成和掌握评分分别显示。无需为了验收修改正式进度。
4. 查看既有19小时目标所在的周（2026-11-09—15），周总结应读取原目标；下一周没有设目标时显示未设置。
5. 导出当前统计CSV；导出完整JSON并预检同一文件应与本机一致。取消导出后原数据不变。

每阶段验收确认后再进入下一阶段，本版不开发第七阶段动画/声音/语库或第八阶段错题/模拟考试/历年报告。云同步、多设备冲突处理不在第一期。
