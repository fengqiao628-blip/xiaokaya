# 小考鸭0.8.0 · 错题、模拟考试与历年报告

2026-11-17，第八阶段，数据库V7。沿用原桌面图标、原安装身份和本地数据位置，继续离线使用。Serena声音、学习伙伴及原有计时、统计和备份功能保留。

## 新入口

左侧“练习、错题与模拟”包含四页：

1. **练习记录**：先选择年度科目，再填日期、来源及总题数/答对/答错/未答。正确率以已作答为分母，未答不计入分母；作废记录保留但不进入正确率。引用学习记录不会再增加实际时长。
2. **错题与复习**：手工收录题干、选项、答案、解析、错因及标签，可关联练习和章节。复习时先看题、再展开答案，记录答对/答错/不确定。复习历史保存当时内容；后来修改题目不会改写旧记录。掌握评价由自己标记，归档保留历史。
3. **模拟考试**：新建试卷、日期、时限和满分，成绩留空表示未记录，0分是有效成绩。进入“模拟计时与试题”启动原有陪伴倒计时，暂停不计时，到时核对并保存实际时长。一次只能有一个未结束计时；已有待核对计时先处理。可另选已有确认学习记录作为来源。逐题得分与试卷总成绩分别维护，模拟成绩不会自动改动正式考试结果或完成任务。
4. **历年冻结报告**：选择备考年度，确认生成当前快照。范围包括该年度科目跨公历年的学习记录和已归档科目。后续补录、作废或编辑不会改旧报告；需要更新时另生成一版。章节评价只表示生成时状态，未重建过去每一天。完整JSON包含所有版本。

列表每页20条，可筛选年度科目、搜索和访问末页。查看旧归档科目记录无需重新选科；新增或编辑归档科目内容时，先在年度档案恢复该周期。

## 升级前与首次打开

1. 旧版先保存正在填写的内容，导出完整JSON并另存；完全退出“小考鸭”。
2. 运行Xiaokaoya-Setup-0.8.0-x64.exe，使用原Windows账号覆盖原安装。安装结束不自动启动。
3. 从原桌面图标打开。首次从V6升级时，程序先保存并回读验证V6保护快照，随后事务内升级至V7；保护失败或迁移事务失败会停止，保留原库。
4. “关于与数据”显示v0.8.0；核对原科目、任务和21分钟/1分钟等本机原有实际数据。旧待核对计时继续待核对，不会被自动确认或累加。请以自己的最新记录为准。
5. 可在新入口查看四页，导出新的V7完整JSON，并用同文件预检核对内容一致，无需执行恢复。

## 完整备份与回退边界

V7完整JSON包括全部新旧表、错题复习内容快照及报告。CSV仍用于表格查看，不能替代恢复。完整文件读写上限保持256MiB；本机快照的日常及保护保留策略不变。

**旧0.7.4不能直接读取V7，也不能读取V7备份。仅覆盖安装旧程序不等于回退。** 升级前保留的V6保护文件可由0.7.4在空的隔离目录恢复并已纳入演练；它不包含升级后新增的错题、模拟和报告。

需要正式回退时先停止操作，保存V7完整JSON及升级前V6文件，联系开发者执行受验证方案：完全退出后保留整个V7数据目录的完整副本，在隔离旧程序/空目录验证V6恢复、记录和指纹，再处理正式入口。不要删除或覆盖当前IndexedDB，也不要让旧程序直接打开V7目录。原V7副本及新记录始终保留，不能用V6恢复声称保留了V7新增数据。

## 验证的实际范围

本阶段使用真实Electron、真实旧版编译程序和隔离数据演练升级、恢复、故障及重开。长期测试为2023—2027五个合成年度、5万学习记录及片段、1万任务与1万错题；它验证大数据量及跨年度行为，不等于已经真实使用五年。原正式数据首次V7迁移及安装后核对单独记录，不把隔离测试当作正式验收。

程序无需服务器、账号、Node、Python或语音模型。appId、NSIS GUID、%APPDATA%\Xiaokaoya\、其profile子目录、app://xiaokaoya及XiaokaoyaStudy保持原合同。卸载保留学习数据；换电脑仍使用完整JSON预检恢复，暂不提供云同步或多设备自动合并。
