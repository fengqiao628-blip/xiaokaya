# 第七阶段0.7.1 · 离线朗读与伙伴动态修正

日期：2026-11-17。用户提出增加语音朗读，并反馈伙伴总是闭眼、动态不明显。范围仍属第七阶段，不进入第八阶段。

## 原因和处理

原首页将没有正在计时的情形也映射为rest，因此待机长期显示闭眼枕头图；原呼吸幅度仅2px，动作不易察觉。现在新增五位伙伴的idle及idle-blink素材，默认睁眼待机，学习时看书点头，明确暂停时休息，点击摇摆回应；移动内层图像，点击区域保持稳定。系统减少动态及用户关闭动画继续生效，不强制覆盖原偏好。历史完成仍只显示开心姿态，不补播过去庆祝。

本机Electron的Web Speech API虽存在，实际getVoices返回空列表。原生探测确认Windows SAPI提供Microsoft Huihui离线中文声音，因此使用按需启动的隐藏PowerShell/SAPI辅助进程。仅选择已安装的微软中文Desktop语音，未接入在线TTS。其他电脑缺声音时明确提示并降级为文字，不影响计时和数据。

文字通过UTF-8 JSON stdin传递；命令固定并以EncodedCommand启动，不把用户文字拼入命令。SAPI以flags19（async、purge、not-XML）读取纯文本，新一句替换旧一句，不允许把自定义语句当成SSML、文件名或脚本执行。IPC限制原窗口可信origin，严格校验文字长度、声音标识、语速和音量。主进程持有总静音策略与取消代数，阻止设备预热后迟到的播报。进程关闭时取消语音并回收辅助进程。

参考微软原始资料：[SpeechVoiceSpeakFlags](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/ms720892(v=vs.85))、[Basic synthesis](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/ee125075(v=vs.85))。

## 产品规则与数据边界

提供每日一句点读、当前鼓励点读、停止、试听、本机声音和语速选择。自动模式可选关键状态，或加学习中每5分钟；默认仅手动。稳定事件键去重，两个鼓励卡不重复朗读同一事件。开关关闭、音量0、窗口离开、锁屏/休眠、备份及恢复均取消，启动与恢复不补播历史事件。声音故障只影响朗读。

自动模式、声音选择和语速属于本次打开的临时选择，重开及恢复后回到手动；无新数据库字段、备份字段或迁移。已有总开关、音量、动画等V6偏好仍按原规则保存和备份。数据库V6/JSON格式1，以及appId、NSIS身份、origin、Session、userData、sessionData和数据库名称全部不变。原0.7.0安装包、ZIP、摘要和已安装ASAR另存于.runtime/baseline/0.7.0-before-speech，未将其标记为已人工验收基线。
